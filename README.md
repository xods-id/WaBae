# Wa Bae (WA Bae!)

Modul Xposed / LSPosed WhatsApp Modern, Super Enteng, Bebas Bloatware, dan Anti-Slop karya **xods-id**.

## Fitur Utama
- **Tampilan Privasi Modern (Material 3 Bento Cards)**: UI terstruktur, dynamic colors Monet, dan no emoji slop.
- **Mode Siluman (Ghost Mode)**: Sekali klik untuk stealth total (bekukan last seen + hide online + invisible view).
- **Privasi Lengkap**:
  - Bekukan Terakhir Dilihat (*Freeze Last Seen*)
  - Centang Biru Pas Dibalas (*Blue on Reply*)
  - Sembunyikan Centang Dua / Sedang Mengetik / Rekam Suara
  - Liat Status Tanpa Ketahuan
  - Bypass Media Sekali Lihat (*View Once*)
  - Anti Tarik Pesan
- **Kebal Expired 2099**: WhatsApp tidak akan pernah mogok kadaluarsa.
- **Arsitektur Sat-Set**: Didukung oleh YukiHookAPI & Jetpack Compose.
